RULES
-----
1. Keep the filename EXACTLY the same (lowercase, .jpg, no spaces).
2. Keep the file in this folder: /public/portfolio-assets/
3. Any JPG works. Matching the aspect ratio above avoids cropping,
   since images are displayed with object-fit: cover.
4. Do not rename, move, or add suffixes - the code references these
   exact paths, e.g. /portfolio-assets/thumnailimg1.jpg
